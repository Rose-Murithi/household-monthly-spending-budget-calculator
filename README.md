# Household Monthly Spending & Budget Calculator

## Project Overview

This beginner Excel portfolio project applies fundamental Excel skills
to a realistic household budgeting scenario.

The project organizes monthly income and household expenses, calculates
expense statistics, and compares spending against available income to
support basic budgeting decisions.

## Objective

The objective of this project is to demonstrate how fundamental Excel
skills can be used to organize, calculate, analyze, and summarize
financial information.

## Excel Skills Demonstrated

- Cell addresses and references
- Basic arithmetic and multiplication
- SUM
- AVERAGE
- COUNT
- IF
- ROUND
- MAX
- MIN
- MEDIAN
- Basic financial calculations
- Currency and number formatting
- Spreadsheet organization
- Basic data analysis

## Project Sections

### Monthly Income Summary
Calculates total monthly income from different income sources.

### Monthly Expense Analysis
Records household expenses across January to December and calculates
average monthly expenses.

### Expense Statistics
Summarizes expenses using COUNT, MAX, MIN, MEDIAN, and RANGE calculations.

### Budget Analysis
Compares monthly income and expenses to determine whether spending is
within or above the available budget.

## Key Question

Are household expenses within the available monthly income?
